# 수업 사용 안내

## 준비

- 기기: Windows/macOS/ChromeOS 의 **데스크톱 Chrome 또는 Edge**. 태블릿은 세로 배치로 화면이 바뀌지만 Bluetooth 지원 여부는 기기마다 다르다.
- 주소: 배포된 HTTPS 주소(Cloudflare) 또는 교사용 PC 의 `http://localhost:5173`. HTTP 로 연 다른 PC 주소에서는 Bluetooth 연결이 되지 않는다.
- 센서: Go Direct Current Probe(GDX-CUR), Go Direct Voltage Probe(GDX-VOLT). 충전 상태를 확인하고, 다른 앱(Graphical Analysis 등)과 동시에 연결하지 않는다. 구형 유선 Vernier 센서는 이 앱으로 직접 연결할 수 없다.
- 교구: 저전압 전원(1.5~3 V) 또는 전지, 정격이 맞는 전구, 고정 저항(예: 100 Ω·220 Ω·330 Ω, 1/4 W 이상), 스위치, 가지별 스위치가 있는 병렬 회로판, 도선.

### 저항 정격 확인
교사용 설정의 소비 전력표가 `P = V²/R` 로 계산한다. 1/4 W 저항 기준:

| 저항 | 1.5 V | 3 V |
| --- | --- | --- |
| 100 Ω | 15 mA, 23 mW (여유) | 30 mA, 90 mW (여유) |
| 220 Ω | 6.8 mA, 10 mW (여유) | 13.6 mA, 41 mW (여유) |
| 330 Ω | 4.5 mA, 7 mW (여유) | 9.1 mA, 27 mW (여유) |

전구는 정격 전압과 예상 전류를 따로 확인하고, 전류 센서 범위 스위치를 예상 전류에 맞춘다(±1 A / ±0.1 A).

### 안전
- 전류 센서는 **직렬**, 전압 센서는 측정 대상 **양단에 병렬**.
- 전류 센서를 전원 양단에 직접 연결하지 않는다.
- 배선을 바꾸기 전에 전원을 끈다. 앱의 ‘측정 정지’ 는 전원을 끄지 않는다.
- 전류 제한이나 보호 저항이 있는 전원을 쓴다.

## 수업 흐름 (한 탐구 기준, 약 45분)

1. **홈** — 탐구 카드에서 ‘새 탐구 시작’. 센서 연결 상태와 연습 모드 여부가 홈 상단에 보인다.
2. **실험 준비** — 준비물·안전 안내·배선 확인 체크리스트(직접 눈으로 확인). 센서를 연결하고 ‘실시간 값 보기’ 로 값이 들어오는지만 확인한다(기록되지 않음). 전류 센서는 **본체의 범위 스위치를 보고 앱에서 같은 값을 선택**한다. 영점이 필요하면 리드를 단락한 뒤 ‘영점 맞추기’.
3. **예측(P)** — 예상 결과(선택·막대·그래프)와 이유, 확신 정도를 적고 제출. 최초 예측은 보존되고 수정은 이력으로 쌓인다. 예측 전에는 결과 그래프·힌트가 보이지 않는다.
4. **관찰(O)** — 왼쪽 회로도의 측정 위치를 고르고 배선 순서를 따라 연결한 뒤 ‘측정 시작’. 값이 안정되면 그래프를 드래그하거나 ‘마지막 2초’ 로 안정 구간을 골라 ‘기록표에 저장’. 위치를 옮길 때는 전원을 끄고 센서를 뺀 자리를 도선으로 복원한다. 같은 위치를 다시 재면 반복 번호가 붙는다.
5. **설명(E)** — 기록표에서 측정값을 선택해 근거 칸에 인용하고, 주장·개념 설명·예측과 달라진 점·더 알고 싶은 점을 적는다. ‘생각해 볼 질문’ 은 수치를 단순 규칙으로 비교해 만든 질문이며 채점이 아니다. 개념 모형과 힌트는 교사 설정의 공개 시점에 따라 보인다.
6. **탐구 정리** — 예측·결과·설명을 한눈에 보고 CSV/JSON 내보내기, 인쇄용 보고서. ‘탐구 완료로 표시’.

한 탐구를 끝내지 않아도 다른 탐구를 시작할 수 있고, 홈의 ‘저장한 탐구 이어하기’ 로 돌아올 수 있다.

## 탐구별 요점

- **탐구 1** A(전구 앞) → B(전구 뒤) → C(돌아가는 구간) → A 재확인 순서. 전지 상태·접촉이 달라질 수 있음을 메모한다. 값이 정확히 같지 않다고 바로 오답 처리하지 않도록, 표준편차와 첫 A·마지막 A′ 를 함께 본다.
- **탐구 2** 저항을 고정하고 전압을 4~6단계로. 전원 설정값이 아니라 **측정한 저항 양단 전압**을 쓴다. 두 센서는 동기화되지 않으므로 같은 관찰 구간의 평균을 한 쌍으로 저장한다. 직선 적합은 관찰 후 선택하며 원점을 강제하지 않고, 기울기(I/V)를 저항이라고 부르지 않는다. 다른 저항 비교는 선택 활동.
- **탐구 3** 조건 A(같은 저항), B(다른 저항)에서 V1 → V2 → V전체. 음수는 절댓값으로 바꾸지 않고 클립 방향을 확인한다. 공식 암기·혼합 회로는 다루지 않는다.
- **탐구 4** 조건 A(가지 하나) → B(같은 저항 둘) → C(다른 저항 둘). I전체 → I1 → I2. 전압을 재지 않았다면 “전원 전압 유지” 는 확인되지 않은 것으로 표시된다.

## 연습 모드 (모의 데이터)

센서가 없을 때 앱 사용법을 익히는 용도. 상단 ‘연습 모드’ 버튼으로 직접 켠다. 켜진 동안 시작한 탐구는 **모의 데이터 세션**으로 분리 저장되고 모든 화면·보고서·CSV 에 ‘모의 데이터(mock)’ 로 표시된다. 모의 회로 조작 패널에서 전원 전압·센서 위치·가지 스위치만 바꿀 수 있다. 실측 연결이 실패해도 자동으로 연습 모드로 바뀌지 않는다.

## 교사용 설정

같은 기기에서 수업 흐름을 맞추는 편의 설정(사용할 탐구, 힌트 공개 시점, 기본 측정 주기, 예시 저항·전압). 서버 인증이 없으므로 보안이나 부정행위 방지 기능이 아니다.

## 데이터 다루기

- 저장: 자동(IndexedDB). 측정 중에도 2초마다 원자료를 저장한다. 저장 공간이 부족하면 상단에 안내가 뜬다. ‘저장한 탐구 → 전체 초기화’ 는 확인 문구 입력이 필요하다.
- 내보내기: 원자료 CSV(표본 단위), 조건별 요약 CSV, 세션 JSON(다시 가져오기), 인쇄용 보고서(개별·통합). 인쇄는 브라우저 ‘인쇄 / PDF 저장’.
- 가져오기: ‘저장한 탐구 → 세션 JSON 가져오기’. 구조·단위·버전을 검증하고 출처를 ‘가져온 자료’ 로 표시한다.
- 표준편차는 선택 구간 안 값의 흩어짐이며 센서 정확도나 신뢰구간이 아니다.

## 자주 생기는 문제

| 증상 | 확인할 것 |
| --- | --- |
| 선택창에 장치가 없다 | 센서 전원(LED), 거리, 다른 앱 연결 여부 |
| 연결 실패 | 다른 앱/PC 에 연결되어 있는지, 센서 껐다 켜기 |
| 값이 ‘수신 없음’ | 거리, 배터리 |
| 전류가 100 mA 에서 평평 | ±0.1 A 범위 포화 → 스위치를 ±1 A 로 |
| 전압이 음수 | 클립 방향 |
| 그래프에 끊김 | 측정 중 연결 끊김 — 재연결 후 새 구간으로 기록됨, 끊긴 구간은 저장 불가 |
