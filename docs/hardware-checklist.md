# 실물 센서 검증 체크리스트

자동 테스트(Vitest, Playwright)는 가짜 어댑터와 모의 데이터로 앱 로직을 검증한다. **실제 Bluetooth 연결은 아래를 사람이 실물로 확인해야 한다.**
확인한 날짜·브라우저·OS·펌웨어 버전을 적어 두자. 결과에 따라 `src/sensors/deviceProfiles.ts` 와 `src/sensors/mock/MockDeviceAdapter.ts` 의 채널 정의를 맞춘다.

환경: 데스크톱 Chrome 또는 Edge, HTTPS(배포 주소) 또는 `http://localhost:5173`.

## A. GDX-CUR 단독 연결
- [ ] 센서 전원을 켜고 ‘전류 센서 연결’ 클릭 → 브라우저 선택창에 `GDX-CUR xxxxx` 가 보인다
- [ ] 선택 후 장치 카드에 주문코드·일련번호·채널 목록이 뜬다. 채널 이름과 단위 문자열을 기록: `________ [___]`
- [ ] 단위가 `A` 또는 `mA` 로 보고되어 전류 역할로 등록된다 (아니면 `wrong_device` 안내가 뜬다 → 이슈 기록)
- [ ] 연결 직후 **자동 측정이 시작되지 않는다** (실시간 값이 ‘측정 대기’)
- [ ] ‘실시간 값 보기 시작’ → 값이 들어오고 적용 주기가 표시된다 (요청 100 ms, 표시값: ___ ms)
- [ ] 콘솔에 `godirect`·GATT 오류가 없다

## B. GDX-VOLT 단독 연결
- [ ] 선택창에 `GDX-VOLT xxxxx` 가 보이고 연결된다
- [ ] 채널 목록에 두 채널이 보인다. 이름·번호·단위 기록: 1) `________` 2) `________`
- [ ] 기본 선택이 20 V 채널이다 (아니면 `pickChannelForRole` 의 이름 규칙 수정)
- [ ] 채널 선택을 1 V 채널로 바꾸면 측정 정지 상태에서만 바뀌고 값이 다시 들어온다
- [ ] 클립을 반대로 물리면 음수가 표시된다 (절댓값 처리 없음)

## C. 두 장치 함께 연결
- [ ] 전류·전압 센서를 차례로 연결하면 카드 두 개가 각각 역할 색으로 표시된다
- [ ] 같은 장치를 다시 선택하면 ‘이미 연결된 장치’ 안내가 뜬다
- [ ] 측정 시작 시 두 장치가 모두 ‘측정 중’ 이 되고, 두 그래프가 함께 흐른다
- [ ] 탐구 2 관찰에서 ‘마지막 2초’ 선택 시 전압·전류 표본 수가 모두 최소 표본 수 이상이다

## D. 채널·단위·범위 확인
- [ ] GDX-CUR 범위 스위치를 ±0.1 A 에 두고 앱에서 같은 값을 선택 → 100 mA 넘는 전류에서 ‘포화’ 표시
- [ ] 범위 스위치를 ±1 A 로 바꾸고 앱 선택도 바꿈 → 포화 표시 사라짐 (앱은 스위치를 읽지 못하므로 사용자가 바꿔야 함)
- [ ] 장치가 보고한 `minValue/maxValue` 를 콘솔에서 확인: `sensorManager.getDevices()[0].channel`
- [ ] 수 mA 수준 전류에서 ‘해상도 부근’ 표시가 적절한지 확인

## E. 측정 시작·정지 반복
- [ ] 관찰 화면에서 시작→정지를 10회 반복해도 오류·누수 없이 동작한다 (`measurements-started/stopped` 대기 시간 체크)
- [ ] 정지 후 그래프에 새 점이 추가되지 않는다
- [ ] 영점 맞추기(리드 단락) 후 오프셋이 표시되고, 해제하면 원래 값으로 돌아온다

## F. 측정 중 연결 해제와 재연결
- [ ] 측정 중 센서 전원을 끄면 몇 초 안에 ‘연결 끊김’ 으로 바뀌고 실시간 값이 사라진다 (측정 소요: ___ 초)
- [ ] 그래프에 끊김이 표시되고, 기록표 저장 시 끊김을 포함한 구간은 거부된다
- [ ] 센서를 다시 켜고 ‘재연결’ 클릭 → 선택창 없이 연결되는지 (안 되면 ‘다시 연결’ 로 새로 선택). 결과: ______
- [ ] 재연결 후 새 구간으로 기록되고 끊긴 사이가 직선으로 이어지지 않는다
- [ ] 센서를 멀리 가져가 값이 끊기면 ‘수신 없음’ 표시가 뜬다

## G. 화면 전환 후 구독 유지·정리
- [ ] 준비 화면에서 실시간 보기 중 예측 화면으로 가도 헤더 상태가 ‘측정 중’ 으로 유지된다
- [ ] 관찰 화면 진입 시 준비용 실시간 보기가 자동 정지되고, ‘측정 시작’ 으로만 기록이 시작된다
- [ ] 관찰 화면을 떠나면 기록이 정지되고 콘솔에 중복 이벤트가 없다 (`value-changed` 당 그래프 점 1개)
- [ ] 다른 탐구로 이동해도 연결은 유지된다

## H. 배포된 HTTPS 주소에서 실제 연결
- [ ] Cloudflare 배포 주소에서 선택창이 열리고 연결된다
- [ ] 응답 헤더에 `Permissions-Policy: bluetooth=(self)` 가 있다 (개발자 도구 → Network)
- [ ] `/inquiry/1/<id>` 를 새로고침해도 200 으로 열린다 (SPA 라우팅)
- [ ] 새로고침 후 Bluetooth 는 다시 연결해야 한다는 안내가 맞다

## I. 다른 앱이 센서를 사용 중일 때
- [ ] Graphical Analysis 등 다른 앱에 연결된 상태에서 연결 시도 → 선택창에 안 보이거나 연결 실패
- [ ] 실패 시 ‘다른 앱이 사용 중일 가능성’ 안내가 뜬다. 실제 오류 메시지 기록: ______

## J. 수업 전 마지막 점검
- [ ] 전류 센서는 직렬, 전압 센서는 병렬로 연결하는 그림이 실제 교구와 맞다
- [ ] 저항 소비 전력표(교사용 설정)가 사용하는 저항 정격과 맞다
- [ ] 전구 정격 전압·예상 전류를 전류 센서 범위에 맞췄다
- [ ] 보고서 인쇄에서 그래프·표가 잘리지 않는다
